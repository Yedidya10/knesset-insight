## תכונות מתוכננות

### 2.1 חיפוש גלובלי חכם

חיפוש אחד שמחפש בכל הישויות:

```
[🔍 חיפוש חברי כנסת, חוקים, הצבעות...]

תוצאות:
├── 👤 חברי כנסת (3 תוצאות)
│   ├── יריב לוין — שר המשפטים
│   └── ...
├── 📜 חוקים (5 תוצאות)
│   ├── חוק יסוד: הלאום — שלב: אושר
│   └── ...
├── 🗳️ הצבעות (12 תוצאות)
│   └── ...
└── 🏛️ ועדות (2 תוצאות)
    └── ...
```

**דרישות טכניות:**

- Full-text search ב-PostgreSQL (tsvector/tsquery)
- חיפוש בעברית עם stemming (ניתוח מורפולוגי בסיסי)
- Debouncing + instant results (כתיבה חיה)
- תוצאות מקובצות לפי סוג ישות
- מטמון Redis לשאילתות נפוצות

**יישום מומלץ:**

```typescript
// tRPC router חדש: search
search.global → input: { query: string, types?: EntityType[] }
  → output: { members: [...], bills: [...], votes: [...], committees: [...] }
```

### 2.2 דף חבר כנסת מורחב — 🟡 חלקי (70%)

מעבר לפרופיל בסיסי — דף מקיף שמספר את "הסיפור" של חבר הכנסת:

#### מה יושם ✅

- תמונה, שם, סיעה, תפקידים, סטטוס
- סטטיסטיקות הצבעה (בעד/נגד/נמנע/נעדר)
- 30 הצבעות אחרונות
- רשימת חוקים שיזם (`MemberBillsList`)
- חברות בוועדות (ועדות בניהולו)
- היסטוריית סיעות לפי כנסות
- טאב יושרה מלא (`IntegrityTab`) — תיקים, קשרי תאגידים, לוביסטים
- קשרי תאגידים (`memberCorporateAffiliations`)
- קשרי לוביסטים (`memberLobbyistConnections`)

#### מה חסר — כרטיסיות (Tabs) 🚧

> הממשק הנוכחי הוא לינארי (סקשנים ברצף). יש לארגן מחדש בממשק טאבים.

**סקירה כללית:**

- תמונה, שם, סיעה, תפקידים
- סטטיסטיקות מפתח: % נוכחות בהצבעות, מספר יוזמות חקיקה, מספר חברויות בוועדות
- "מד קו" — אחוז הצבעה עם קואליציה/אופוזיציה

**היסטוריית הצבעות:**

- רשימת הצבעות עם סינון מתקדם
- גרף מגמות לאורך זמן
- "הצבעות בולטות" — הצבעות שבהן חבר הכנסת הצביע נגד הרוב בסיעה שלו

**יוזמות חקיקה:**

- חוקים שיזם/צורף אליהם
- סטטוס כל חוק (גרף Sankey מהצעה לאישור)
- שיתופי פעולה — עם מי יזם הכי הרבה

**פעילות בוועדות:**

- חברות בוועדות
- נוכחות בישיבות
- נושאים שהועלו

**היסטוריה פוליטית:**

- מעברים בין סיעות (timeline)
- תפקידים לאורך השנים
- כנסות שבהן כיהן

### 2.3 הצבעות — תצוגה inline בדפי חקיקה ✅

> **הכרעה אדריכלית:** הצבעות לא יקבלו דף נפרד. כל ההצבעות מוצגות בהקשר הצעת החוק שלהן.
> Route `/votes/[id]` קיים רק כ-redirect legacy ל-`/legislation/[billId]`.

#### מה יושם ✅

**InteractiveStagePipeline** — ויזואליזציית שלבי חקיקה אינטראקטיבית:

- Stepper אופקי (דסקטופ) / אנכי (מובייל) עם שלבי חקיקה
- לחיצה על שלב פותחת `StageVotePanel` עם ההצבעות הרלוונטיות
- זיהוי אוטומטי של הסתייגויות (regex עברי) עם קיבוץ מתקפל

**MiniVoteCard** — כרטיס הצבעה קומפקטי:

- כותרת, תאריך, סטטוס (אושר/נדחה)
- `VoteTalliesBar` — בר ויזואלי צבעוני (ירוק/אדום/צהוב)
- לחיצה מרחיבה ל-`InlineVoteDetail`

**InlineVoteDetail** — פירוט הצבעה מלא (lazy-loaded):

- פילוח לפי סיעות (via tRPC `votes.detail`)
- רשימת מצביעים עם תמונות ושמות
- בעד / נגד / נמנע / נעדר לכל סיעה

**פונקציונליות אדמין:**

- הצמדת הצבעה מחדש לחוק
- שינוי שלב חקיקה של הצבעה

#### מה חסר 🚧

- ❌ **מדד קונטרוברסיאליות** — אין שדה `controversiality` בסכמת הצבעות
- ❌ **"שוברי שורות"** — זיהוי חברי כנסת שהצביעו נגד סיעתם (נתונים קיימים, חסר חישוב + UI)
- ❌ **הצבעות קשורות** — Backend מוכן (`votesRouter.byId` מחזיר related), חסר UI
- ❌ **קישור לפרוטוקול** — `protocolUrl` קיים בסכמה, לא מוצג

### 2.4 דפי ועדות — ✅ מושלם

#### מה יושם ✅

- רשימת ועדות (פעילות/לא פעילות) עם סינון לפי סוג — כרטיסים ניתנים ללחיצה
- סכמת DB: `committees` (chairmanId, committeeType, isActive, knessetNum, metadata)

- Relations מוגדרים בסכמה
- Skeleton loading (רשימה + פרטים)
- **דף פרטים לכל ועדה** (`/committees/[id]`):
  - כותרת + badges (סוג ועדה, סטטוס, מספר כנסת)
  - כרטיס יו"ר (אווטר + קישור לפרופיל)
  - כרטיס מידע (סוג, סטטוס, מספר ישיבות)

  - `generateMetadata()` לSEO

## ביצועים ו-UX

### מדיניות טעינה

| אלמנט  | אסטרטגיה                                      |
| ------ | --------------------------------------------- |
| רשימות | Infinite scroll עם skeleton loading           |
| גרפים  | Lazy load + placeholder                       |
| תמונות | Next.js Image optimization + blur placeholder |
| נתונים | Stale-while-revalidate via tRPC + Redis       |
| חיפוש  | Debounce 300ms + instant cache                |

### PWA Offline

- **סטטי**: דפים ראשיים, CSS, JS — CacheFirst
- **API**: תגובות tRPC אחרונות — StaleWhileRevalidate
- **תמונות**: NetworkFirst עם fallback לתמונת ברירת מחדל
- **חיפוש**: Offline-only אם יש נתונים מקושים

### SEO — ✅ מושלם (בסיסי) / 🟡 חלקי (JSON-LD)

- ✅ `generateMetadata()` ב-10+ דפים (home, members list+detail, legislation list+detail, committees list+detail, politics, elections, governments list+detail, budget)
- ✅ Open Graph + Twitter Cards לכל הדפים
- ✅ `sitemap.ts` דינאמי (static pages + members/bills/governments/committees across 4 locales)
- ✅ `robots.ts` (allow all, disallow /api/ + /admin/)
- ✅ `metadataBase` + hreflang alternates ב-layout
- ✅ namespace `seo` ב-i18n (he, en, ar, ru)
- ❌ Structured data (JSON-LD) — נדחה ל-P1
