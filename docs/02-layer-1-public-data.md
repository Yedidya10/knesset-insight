# 02 — שכבה ראשונה: מידע ציבורי לקריאה וחיפוש

## עקרון מנחה

> כל אזרח יכול לגלוש, לחפש ולצרוך מידע פרלמנטרי **ללא רישום, ללא עלות, ללא הגבלה**.
> זו השכבה שמביאה את עיקר הערך — נגישות מידע ממשלתי ברמה הגבוהה ביותר.

## תכונות מתוכננות

### 2.1 חיפוש גלובלי חכם

חיפוש אחד שמחפש בכל הישויות:

```
[🔍 חיפוש חברי כנסת, חוקים, הצבעות...]

תוצאות:
├── 👤 חברי כנסת (3 תוצאות)
│   ├── יריב לוין — שר המשפטים
│   └── ...
├── 📜 חוקים (5 תוצאות)
│   ├── חוק יסוד: הלאום — שלב: אושר
│   └── ...
├── 🗳️ הצבעות (12 תוצאות)
│   └── ...
└── 🏛️ ועדות (2 תוצאות)
    └── ...
```

**דרישות טכניות:**

- Full-text search ב-PostgreSQL (tsvector/tsquery)
- חיפוש בעברית עם stemming (ניתוח מורפולוגי בסיסי)
- Debouncing + instant results (כתיבה חיה)
- תוצאות מקובצות לפי סוג ישות
- מטמון Redis לשאילתות נפוצות

**יישום מומלץ:**

```typescript
// tRPC router חדש: search
search.global → input: { query: string, types?: EntityType[] }
  → output: { members: [...], bills: [...], votes: [...], committees: [...] }
```

### 2.2 דף חבר כנסת מורחב

מעבר לפרופיל בסיסי — דף מקיף שמספר את "הסיפור" של חבר הכנסת:

#### כרטיסיות (Tabs):

**סקירה כללית:**

- תמונה, שם, סיעה, תפקידים
- סטטיסטיקות מפתח: % נוכחות בהצבעות, מספר יוזמות חקיקה, מספר חברויות בוועדות
- "מד קו" — אחוז הצבעה עם קואליציה/אופוזיציה

**היסטוריית הצבעות:**

- רשימת הצבעות עם סינון מתקדם
- גרף מגמות לאורך זמן
- "הצבעות בולטות" — הצבעות שבהן חבר הכנסת הצביע נגד הרוב בסיעה שלו

**יוזמות חקיקה:**

- חוקים שיזם/צורף אליהם
- סטטוס כל חוק (גרף Sankey מהצעה לאישור)
- שיתופי פעולה — עם מי יזם הכי הרבה

**פעילות בוועדות:**

- חברות בוועדות
- נוכחות בישיבות
- נושאים שהועלו

**היסטוריה פוליטית:**

- מעברים בין סיעות (timeline)
- תפקידים לאורך השנים
- כנסות שבהן כיהן

- קישור לפרוטוקול הדיון (אם קיים)
- השוואה עם הצבעות דומות בעבר

### 2.4 דפי ועדות (חדש)

```
ועדות הכנסת
├── ועדות קבועות
│   ├── ועדת חוקה, חוק ומשפט
│   ├── ועדת הכספים
│   ├── ועדת חוץ וביטחון
│   └── ...
├── ועדות מיוחדות
└── ועדות חקירה
```

**לכל ועדה:**

- הרכב (יו"ר, חברים)
- ישיבות אחרונות עם נושאים
- חוקים שנדונו
- סטטיסטיקות פעילות

### 2.5 דפי תקציב (חדש)

**תצוגות:**

1. **Treemap — חלוקת תקציב לפי משרדים**
   - כל משרד = ריבוע, גודל לפי תקציב
   - צבע לפי שינוי מהשנה הקודמת

2. **Sankey — זרימת תקציב**
   - מסעיפים ראשיים → משרדים → תתי-סעיפים

3. **השוואה שנתית**
   - Line chart של סעיפי תקציב לאורך שנים
   - מתואם אינפלציה

4. **תקציב לאזרח**
   - "כמה מכל ₪100 שלך הולכים לביטחון/חינוך/בריאות"

**מקורות נתונים:**

- Open Budget API (כבר מוגדר ב-`app.config.ts`)
- budget_items טבלה (כבר קיימת בסכמה)

### 2.6 דף בחירות (חדש)

- תוצאות בחירות היסטוריות (כנסת 1–25)
- השוואה בין כנסות
- מפת מעברי קולות בין מפלגות
- אחוזי הצבעה לאורך השנים
- כמות מנדטים לפי סיעה (animated bar chart)

### 2.7 ויזואליזציות מתקדמות

#### גרף רשת (Network Graph) — קשרי שיתוף פעולה

```
     [ח"כ א']
    /    |    \
[ח"כ ב'] [ח"כ ג'] [ח"כ ד']
    \    |    /
     [ח"כ ה']

צומת = חבר כנסת
קשת = שיתוף פעולה בחקיקה
עובי הקשת = עוצמת שיתוף
```

#### ציר זמן אינטראקטיבי

ציר זמן אופקי שמראה אירועים פרלמנטריים מרכזיים:

- חקיקה חשובה
- הצבעות דרמטיות
- שינויי קואליציה
- בחירות

#### מפת חום — דפוסי הצבעה

טבלת חברי כנסת × הצבעות, צבע לפי בעד/נגד/נמנע/לא נכח.

## ביצועים ו-UX

### מדיניות טעינה

| אלמנט  | אסטרטגיה                                      |
| ------ | --------------------------------------------- |
| רשימות | Infinite scroll עם skeleton loading           |
| גרפים  | Lazy load + placeholder                       |
| תמונות | Next.js Image optimization + blur placeholder |
| נתונים | Stale-while-revalidate via tRPC + Redis       |
| חיפוש  | Debounce 300ms + instant cache                |

### PWA Offline

- **סטטי**: דפים ראשיים, CSS, JS — CacheFirst
- **API**: תגובות tRPC אחרונות — StaleWhileRevalidate
- **תמונות**: NetworkFirst עם fallback לתמונת ברירת מחדל
- **חיפוש**: Offline-only אם יש נתונים מקושים

### SEO

- Server-side rendering לכל דפי המידע הציבורי
- Structured data (JSON-LD) לחברי כנסת, חקיקה, הצבעות
- Sitemap דינאמי
- Open Graph + Twitter Cards עם thumbnails מותאמים
- Dynamic `<title>` ו-`<meta description>` לכל דף

## הנחיות עיצוב

### Mobile-First

כל ויזואליזציה חייבת לעבוד גם על מסך 320px:

- גרפים מצטמצמים / נגללים אופקית
- טבלאות הופכות לכרטיסים
- Actions ב-bottom sheet

### Dark Mode

- כל ויזואליזציה תומכת ב-dark mode
- צבעי גרפים מותאמים (לא רק invert)

### אנימציות

- Framer Motion לכניסות (כבר מוטמע)
- Count-up לספרות (כבר מוטמע)
- Transitions חלקים בין דפים
- Skeleton loading לכל תוכן דינמי (כבר מוטמע)
