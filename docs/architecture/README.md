## מצב נוכחי (Baseline)

הפרויקט כיום כולל:

- ✅ סכמת בסיס נתונים מקיפה (חברי כנסת, הצבעות, חוקים, סיעות, ועדות, תקציב)
- ✅ API מסוג tRPC עם אנדפוינטים ציבוריים טייפ-סייף
- ✅ דפי צפייה ציבוריים (חברי כנסת, הצבעות, חקיקה, סיעות, מפלגות)
- ✅ תשתית i18n מלאה (עברית, אנגלית, ערבית, רוסית) עם RTL
- ✅ pipeline לסנכרון נתונים מ-9 מקורות
- ✅ תשתית AI abstractit מוכנה (Gemini/OpenAI)
- ✅ PWA עם service worker
- 🚧 אותנטיקציה — מבנה מוכן, טרם מומש
- 🚧 AI Chat — קונפיגורציה מוכנה, טרם נבנה
- 🚧 דפי דשבורד למשתמש — ריקים

## עקרונות מנחים

1. **שקיפות ונגישות** — כל מידע ממשלתי צריך להיות נגיש לכל אזרח
2. **ניטרליות** — הפלטפורמה מציגה נתונים, לא דעות
3. **גמישות** — ארכיטקטורה מודולרית שמאפשרת הרחבה
4. **קוד פתוח** — שמירה על שקיפות הקוד ושיתוף פעולה קהילתי
5. **הגנה על פרטיות** — מינימום איסוף מידע אישי, GDPR-compliant
