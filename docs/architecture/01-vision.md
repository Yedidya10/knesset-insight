# 01 — חזון הפלטפורמה

## מ-"Knesset Insight" ל-"Israel Democracy Insight"

### הרעיון המרכזי

Knesset Insight החלה כפלטפורמה להנגשת נתוני הכנסת הישראלית. אך החזון הוא רחב יותר: **פלטפורמת דמוקרטיה אזרחית מקיפה** שמשלבת מקורות מידע ממשלתיים, עירוניים, אקדמיים ואזרחיים — כדי לאפשר לכל אזרח בישראל להבין, לעקוב ולהשפיע על התהליכים הדמוקרטיים שמשפיעים על חייו.

### מ"נתונים" ל"תובנות"

הפלטפורמה לא רק מציגה נתונים — היא מייצרת **תובנות**:

```
נתונים גולמיים → עיבוד → ויזואליזציה → תובנות → פעולה אזרחית
```

| שכבה       | מה המשתמש מקבל                                                |
| ---------- | ------------------------------------------------------------- |
| **נתונים** | טבלאות, רשומות, מספרים                                        |
| **מידע**   | הקשר — מי הצביע על מה, מתי, באיזה הרכב                        |
| **תובנות** | דפוסים — "ח״כ X הצביע 80% עם הקואליציה למרות שהוא באופוזיציה" |
| **פעולה**  | כלים — מעקב, התראות, השוואה, שיתוף                            |

---

## זרועות הפלטפורמה

### 1. זרוע פרלמנטרית (הליבה — קיים חלקית)

מרכז המידע הפרלמנטרי הנוכחי:

- **חברי כנסת** — פרופילים, היסטוריית הצבעות, יוזמות חקיקה, השתייכות סיעתית
- **הצבעות** — פירוט מלא כולל פיצול לפי סיעות, מדד קונטרוברסיאליות
- **חקיקה** — מעקב אחרי חוקים מהצעה ועד חקיקה, יוזמים, ועדות מטפלות
- **סיעות ומפלגות** — הרכבים, קואליציות, תנועות בין סיעות
- **ועדות** — הרכבים, ישיבות, נושאים נדונים
- **תקציב** — ניתוח הוצאות ממשלתיות לפי משרדים וסעיפים

### 2. זרוע שלטון מקומי (הרחבה עתידית)

שילוב נתוני רשויות מקומיות:

- **מועצות עיריות** — הרכבים, הצבעות, פרוטוקולים
- **תקציבי רשויות** — הוצאות מקומיות, השוואה בין רשויות
- **חוקי עזר** — חקיקה מקומית ותקנות
- **ועדות תכנון** — החלטות תכנון ובנייה
- **שירותים ציבוריים** — איכות שירותים, זמני תגובה, תלונות

**מקורות מידע פוטנציאליים:**

- פורטל הרשויות המקומיות
- משרד הפנים — נתונים פתוחים
- הרשות לשוויון בנטל
- מרכז השלטון המקומי

### 3. זרוע אקדמית-מחקרית (שיתופי פעולה)

שילוב תובנות ומחקרים ממכוני מחקר:

#### המכון הישראלי לדמוקרטיה (IDI)

- **מדד הדמוקרטיה הישראלית** — ציוני ביצוע שנתיים
- **סקרי אמון הציבור** — אמון במוסדות, סקרי עמדות
- **מחקרי חקיקה** — ניתוחי השפעה של חוקים
- **מדד ייצוג** — ייצוג קבוצות אוכלוסייה שונות

#### דמוקרטיה 3.0

- **חדשנות דמוקרטית** — מודלים חדשים של השתתפות אזרחית
- **כלים דיגיטליים** — Best practices בטכנולוגיה אזרחית
- **מדדי פתיחות** — שקיפות ונגישות ממשלתית

#### מכונים נוספים

| מכון                        | תחום                | סוג מידע               |
| --------------------------- | ------------------- | ---------------------- |
| מחקר ביטחון לאומי (INSS)    | ביטחון ומדיניות חוץ | ניתוחי מדיניות         |
| מכון ון ליר                 | חברה ותרבות         | מחקרים חברתיים         |
| טאוב לחקר מדיניות חברתית    | חברה וכלכלה         | נתונים סוציו-אקונומיים |
| שורש — מרכז למדיניות כלכלית | כלכלה               | ניתוחי תקציב           |
| מרכז אדוה                   | שוויון חברתי        | מיפוי פערים            |
| הסדנא לידע ציבורי           | Gov-Tech            | נתונים פתוחים          |

### 4. זרוע משפטית (הרחבה עתידית)

- **פסקי דין בג"ץ** — בנושאים חוקתיים
- **חוות דעת היועמ"ש** — חוות דעת רלוונטיות
- **חוקתיות חוקים** — סטטוס חוקתי של חקיקה

## ערכי ליבה

### 1. ניטרליות ואובייקטיביות

הפלטפורמה **לא מביעה עמדה פוליטית**. היא מציגה נתונים, מדדים ותובנות מבוססות עובדות. כל ניתוח AI יסומן בבירור כ"ניתוח אוטומטי" ולא כעמדת הפלטפורמה.

**כללים מנחים:**

- אין ביטויים ערכיים ("חיובי", "שלילי") אלא רק תיאורים עובדתיים
- כל מדד מלווה בהסבר מתודולוגי
- מקורות מידע מצוטטים תמיד
- ניתוחי AI כוללים הסבר איך הגיעו למסקנה

### 2. נגישות מלאה

- **שפתית** — עברית, אנגלית, ערבית, רוסית (+ אפשרות להוספת שפות)
- **טכנולוגית** — PWA שעובד גם offline, ביצועים גבוהים
- **קוגניטיבית** — ויזואליזציות ברורות, שפה פשוטה, הסברים
- **נגישות WCAG 2.1 AA** — כולל ניווט מקלדת, קוראי מסך, ניגודיות

### 3. פרטיות ואבטחה

- **Minimal Data Collection** — רק מה שנדרש לפונקציונליות
- **אין מכירת מידע** — לעולם
- **GDPR/חוק הגנת הפרטיות** — עמידה מלאה
- **שקיפות** — מדיניות פרטיות ברורה וקצרה
- **מחיקת חשבון** — תמיד זמינה

### 4. קוד פתוח ושיתוף פעולה

- **Open Source** — כל הקוד ב-GitHub
- **API ציבורי** — אפשרות לפתחנים אחרים להשתמש בנתונים המעובדים
- **תרומות קהילתיות** — מנגנון ברור לתרומות קוד ותכנים

## מודל עסקי (ללא מטרת רווח)

הפלטפורמה פועלת כפרויקט **ללא מטרת רווח**:

```
מקורות מימון אפשריים
├── תרומות קהילתיות (GitHub Sponsors, Patreon)
├── מענקים (קרנות דמוקרטיה, civic tech)
├── שיתופי פעולה מחקריים
└── API Premium (עבור שימוש מסחרי בלבד)
```

### עקרון מפתח

> **כל המידע הציבורי נשאר חינמי ופתוח — תמיד.**
>
> תכנים בתשלום יכולים לכלול רק:
>
> - API בקצב גבוה לשימוש מסחרי
> - ניתוחי AI מתקדמים (מעבר למכסה חינמית)
> - ייצוא בכמויות גדולות

## מדדי הצלחה

### מדדים כמותיים

- **משתמשים חודשיים פעילים (MAU)** — יעד: 10K בשנה הראשונה
- **זמן ממוצע באתר** — יעד: > 3 דקות
- **שיעור חזרה** — יעד: > 30% חוזרים תוך חודש
- **כיסוי נתונים** — % של נתוני כנסת שמחופים לעומת הזמינים

### מדדים איכותיים

- **צוטטו בתקשורת** — כמה פעמים נתוני הפלטפורמה צוטטו בכתבות
- **אימוץ בחינוך** — כמה מורים/מרצים משתמשים
- **תרומות קוד** — כמה contributors פעילים
- **שביעות רצון** — סקר NPS רבעוני

---

## עקרונות ארכיטקטוניים לצמיחה

1. **Modular Monolith** — מתחילים כ-monolith עם הפרדה לוגית ברורה, מפרקים ל-microservices רק כשיש צורך
2. **API-First** — כל יכולת נחשפת דרך API לפני שנבנה UI
3. **Event-Driven** — שינויים בנתונים מפיצים events, לא polling
4. **Cache-Heavy** — Redis caching אגרסיבי, נתונים פרלמנטריים משתנים לאט
5. **Progressive Enhancement** — הכל עובד בסיסי ללא JS, UI עשיר מתווסף בהדרגה

## סיכום המסלול

```
Phase 1 (נוכחי): הנגשת נתוני כנסת ← ✅ בתהליך
    ↓
Phase 2: רישום משתמשים + התאמה אישית ← 🚧 הבא
    ↓
Phase 3: שכבה חברתית + שיתופית ← 📋 מתוכנן
    ↓
Phase 4: הרחבה לשלטון מקומי ← 🔮 חזון
    ↓
Phase 5: פלטפורמת דמוקרטיה מקיפה ← 🔮 חזון
```

> מסמך זה הוא "מסמך חי" שמתעדכן עם התפתחות הפרויקט. כל החלטה עתידית נמדדת מול העקרונות שהוגדרו כאן.
